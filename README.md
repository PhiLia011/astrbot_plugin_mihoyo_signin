# astrbot_plugin_mihoyo_signin

AstrBot 米游社每日签到插件：支持 **原神 / 崩坏：星穹铁道 / 崩坏3 / 绝区零 / 崩坏学园2 / 未定事件簿**（国服）。

## 功能

- ✅ **一键签到**：发送「签到」两个字，即可为当前账号的全部游戏签到
- ✅ **多角色签到**：同一游戏中绑定的多个角色会逐个签到
- ✅ 扫码登录（「米游社 登录」，使用米游社 App 扫码后自动保存账号）
- ✅ Cookie 绑定（「米游社 绑定 <cookie>」）
- ✅ **多账号支持**：可绑定多个米游社账号，「米游社 切换 <序号>」切换，自动签到覆盖所有账号
- ✅ 每日自动签到（默认 00:10，可在 WebUI 修改时间与开关各游戏）
- ✅ 签到结果自动推送到绑定时的会话
- ✅ 查询签到状态 / 查看绑定信息 / 解绑（可解绑单个或全部）
- ✅ 管理员一键全员签到（`米游社 全部签到`）
- ✅ **战绩查询**：账号资料、角色面板、武器、圣遗物/遗器、深渊/周期挑战、体力
- ✅ **离线角色图鉴**：原神/星铁/崩坏学园2角色资料、立绘、技能、命座与素材
- ✅ **真人验证码网页**：米游社返回 `1034/10035` 时生成一次性验证链接，验证成功后自动继续查询

## 安装

1. 将本插件目录放入 `AstrBot/data/plugins/`（或通过 WebUI 插件市场安装）
2. 在 WebUI 插件管理中点「重载插件」
3. 首次加载会自动安装依赖 `httpx` / `aiohttp` / `qrcode` / `pillow`
4. 在 WebUI 插件配置中可按需调整每日签到时间与参与游戏

| --- | --- |
| `签到` | 一键签到当前账号的全部游戏（快捷指令） |

| `米游社 全部签到` | 管理员：全员立即签到 |
| `米游社 资料 [游戏] [UID]` | 查询等级、统计与探索度 |
| `米游社 图鉴 [原神/星铁/崩坏2] [角色名]` | 查询角色图鉴，无需绑定账号 |

游戏名可用：`原神`、`崩铁`/`星穹铁道`、`崩坏3`、`绝区零`、`崩坏2`、`未定`。

> 💡 **群聊使用**：指令需以 `/` 开头（如 `/签到`）或 @ 机器人后发送，私聊 / WebChat 可直接发送「签到」。

### 快捷游戏前缀

除扫码登录仍使用 `米游社 登录` 外，角色、体力、深渊和战绩查询可省略「米游社」：

| 前缀 | 游戏 | 示例 |
| --- | --- | --- |
| `#` | 原神 | `#角色 胡桃`、`#体力`、`#深渊` |
| `*` | 崩坏：星穹铁道 | `*角色 流萤`、`*体力`、`*深渊` |
| `%` | 绝区零 | `%角色`、`%体力` |
| `!` | 崩坏3 | `!角色`、`!资料` |
| `^` | 崩坏学园2 | `^角色 布洛妮娅`、`^图鉴` |
| `未定` | 未定事件簿 | `未定 角色`、`未定 体力` |

## 角色图鉴

图鉴使用插件内置数据生成图片，不绑定米游社账号、不请求战绩接口。群聊中可在前面补 `/`，也支持 `mys` 简写。

```text
米游社 图鉴
米游社 图鉴 胡桃
米游社 图鉴 星铁 流萤
米游社 图鉴 崩坏2
米游社 胡桃图鉴
```

当前内置原神 127 位、崩坏：星穹铁道 99 位、崩坏学园2 27 位角色。原神/星铁包含角色称号、属性/命途、生日与声优、满级基础面板、技能摘要、命座/星魂和养成素材；崩坏学园2角色图鉴与立绘来自独立图鉴仓库。

详情图优先借用云崽 [miao-plugin](https://github.com/yoimiya-kokomi/miao-plugin) 的开源图鉴版式，通过 AstrBot 文转图渲染；服务不可用时自动回退到内置 Pillow 渲染。崩坏学园2图鉴数据与图片借用 [bh2-plugin](https://github.com/l52312516-cell/bh2-plugin) 和 [Honkai-Academy-2-Illustrated-Guide](https://github.com/l52312516-cell/Honkai-Academy-2-Illustrated-Guide)。来源和 MIT 许可证记录在 `wiki_assets/NOTICE.txt`。

`米游社 角色` 也已改为图片输出：原神/星铁显示角色图鉴列表或详情，绝区零显示账号角色头像卡，崩坏学园2显示对应角色图鉴。

图鉴底部标注 **DESIGNED BY FIREFLY**。角色头像与游戏资料版权归米哈游所有，仅供学习交流使用。

## 战绩查询

战绩查询默认使用原神，可在参数中加入 `星铁`、`绝区零` 切换游戏。账号存在多个同游戏角色时，可追加 9-10 位游戏 UID。

```text
米游社 资料
米游社 资料 星铁
米游社 角色
米游社 角色 胡桃
米游社 装备 胡桃
米游社 圣遗物 星铁 流萤
米游社 深渊 1
米游社 深渊 星铁
米游社 体力 绝区零
米游社 邦布
```

支持范围：

| 游戏 | 官方可查询内容 |
| --- | --- |
| 原神 | 账号资料、探索度、角色、角色面板、武器、圣遗物、深渊 |
| 星铁 | 账号资料、角色、角色面板、武器/遗器、周期挑战、实时体力 |
| 绝区零 | 账号资料、角色、邦布、实时状态 |
| 崩坏3 / 崩坏2 / 未定 | 当前米游社没有与上述接口同等稳定的公开战绩接口 |

绝区零官方战绩接口暂未提供稳定的式舆防卫和驱动盘明细，因此不会伪造这两类数据。

## 真人验证码网页

当战绩接口返回 `1034`、`10035` 或 `10041` 时，插件会生成一次性链接。用户在网页完成米游社官方极验后，插件把 `challenge / validate / seccode` 返回给米游社并自动重试原查询。

在 WebUI 插件配置中设置：

- `captcha_public_base_url`：查询者能够访问的 HTTPS 地址，例如 `https://bot.example.com`
- `captcha_web_host`：默认 `0.0.0.0`
- `captcha_web_port`：默认 `6199`
- `captcha_ttl`：默认 300 秒

如果机器人部署在家庭网络或内网，需要做端口转发或反向代理。验证链接只对本次查询有效，提交一次后立即失效，不会在网页显示或保存 Cookie。验证码结果也不会写入日志。

## Cookie 获取方法

1. 浏览器**无痕模式**打开并登录 `https://user.mihoyo.com/`
2. 按 `F12` 打开开发者工具，切到 Console（控制台）
3. 输入 `document.cookie` 回车，复制输出内容
4. 发送 `米游社 绑定 <复制的内容>`

> 建议同时登录一次 `https://bbs.mihoyo.com/` 以获得完整 Cookie（含 ltoken / cookie_token）。

## 数据与安全

- 绑定数据（含 Cookie）存储在 AstrBot 的 `data/plugin_data/astrbot_plugin_mihoyo_signin/` 下，更新/重装插件不会丢失；旧版本存放在插件目录的数据会在首次加载时自动迁移
- 账号 Cookie 会过期，过期后自动签到会失败并提示，重新扫码/绑定即可
- 建议使用 aiocqhttp 等支持主动消息的平台，否则签到结果推送可能不可达

## 说明

- 「签到」为全局快捷指令，若与其他签到类插件冲突，可删除 main.py 中的 `quick_sign` 方法（约 45 行）
- 本项目仅供学习交流使用，请勿滥用
- 米游社接口（act_id、DS 盐、app_version）若失效，可在 WebUI 插件配置的高级设置中修改，或等待插件更新

## 常见问题

- 提示「网络出小差了」：原神/绝区零签到需要 `x-rpc-signgame` 专用请求头，请确认使用 v2.0.1 或更高版本
- 提示验证码或风控：本次签到没有完成，请稍后在米游社 App 手动签到；插件不会把验证码回执误报为成功
- 提示首次绑定：请先在该游戏的米游社签到页手动签到一次，再使用插件签到
