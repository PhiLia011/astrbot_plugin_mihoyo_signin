# astrbot_plugin_mihoyo_signin

AstrBot 米游社每日签到插件：支持 **原神 / 崩坏：星穹铁道 / 崩坏3 / 绝区零 / 崩坏学园2 / 未定事件簿**（国服）。

## 功能

- ✅ **一键签到**：发送「签到」两个字，即可为当前账号的全部游戏签到
- ✅ **多角色签到**：同一游戏中绑定的多个角色会逐个签到
- ✅ 扫码登录绑定（「米游社 扫码」，米游社 App 扫二维码自动绑定）
- ✅ Cookie 绑定（「米游社 绑定 <cookie>」）
- ✅ **多账号支持**：可绑定多个米游社账号，「米游社 切换 <序号>」切换，自动签到覆盖所有账号
- ✅ 每日自动签到（默认 00:10，可在 WebUI 修改时间与开关各游戏）
- ✅ 签到结果自动推送到绑定时的会话
- ✅ 查询签到状态 / 查看绑定信息 / 解绑（可解绑单个或全部）
- ✅ 管理员一键全员签到（`米游社 全部签到`）

## 安装

1. 将本插件目录放入 `AstrBot/data/plugins/`（或通过 WebUI 插件市场安装）
2. 在 WebUI 插件管理中点「重载插件」
3. 首次加载会自动安装依赖 `httpx` / `qrcode` / `pillow`
4. 在 WebUI 插件配置中可按需调整每日签到时间与参与游戏

## 使用

| 指令 | 说明 |
| --- | --- |
| `签到` | 一键签到当前账号的全部游戏（快捷指令） |
| `米游社 扫码` | 扫码登录自动绑定（建议私聊使用） |
| `米游社 绑定 <cookie>` | 绑定 Cookie |
| `米游社 签到 [游戏]` | 指定游戏签到，不填则全部 |
| `米游社 查询 [游戏]` | 查询本月签到状态 |
| `米游社 我的` | 查看所有绑定账号 |
| `米游社 切换 <序号>` | 多账号切换默认账号 |
| `米游社 解绑 [全部]` | 解绑当前账号（加「全部」解绑所有） |
| `米游社 全部签到` | 管理员：全员立即签到 |
| `米游社 帮助` | 使用帮助 |

游戏名可用：`原神`、`崩铁`/`星穹铁道`、`崩坏3`、`绝区零`、`崩坏2`、`未定`。

> 💡 **群聊使用**：指令需以 `/` 开头（如 `/签到`）或 @ 机器人后发送，私聊 / WebChat 可直接发送「签到」。

## Cookie 获取方法

1. 浏览器**无痕模式**打开并登录 `https://user.mihoyo.com/`
2. 按 `F12` 打开开发者工具，切到 Console（控制台）
3. 输入 `document.cookie` 回车，复制输出内容
4. 发送 `米游社 绑定 <复制的内容>`

> 建议同时登录一次 `https://bbs.mihoyo.com/` 以获得完整 Cookie（含 ltoken / cookie_token）。

## 数据与安全

- 绑定数据（含 Cookie）存储在 AstrBot 的 `data/plugin_data/astrbot_plugin_mihoyo_signin/` 下，更新/重装插件不会丢失；旧版本存放在插件目录的数据会在首次加载时自动迁移
- 账号 Cookie 会过期，过期后自动签到会失败并提示，重新扫码/绑定即可
- 建议使用 aiocqhttp 等支持主动消息的平台，否则签到结果推送可能不可达

## 说明

- 「签到」为全局快捷指令，若与其他签到类插件冲突，可删除 main.py 中的 `quick_sign` 方法（约 45 行）
- 本项目仅供学习交流使用，请勿滥用
- 米游社接口（act_id、DS 盐、app_version）若失效，可在 WebUI 插件配置的高级设置中修改，或等待插件更新

## 常见问题

- 提示「网络出小差了」：原神/绝区零签到需要 `x-rpc-signgame` 专用请求头，请确认使用 v2.0.1 或更高版本
- 提示验证码或风控：本次签到没有完成，请稍后在米游社 App 手动签到；插件不会把验证码回执误报为成功
- 提示首次绑定：请先在该游戏的米游社签到页手动签到一次，再使用插件签到
